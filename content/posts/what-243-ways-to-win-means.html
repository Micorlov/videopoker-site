On a slot with paylines, a win has to sit on a route drawn in advance: the middle row, a V shape, a zig-zag. Matching symbols that land off those routes pay nothing. A 243-ways game throws the routes away. It asks one question per symbol: does it appear somewhere on the first reel, somewhere on the second, somewhere on the third, and so on, reading from the left without a gap? Where it sits on each reel no longer matters.

Where 243 comes from

Picture the grid as five columns of three cells. A path across it picks one cell from each column. There are three choices on the first reel, three on the second, and so on, so the number of distinct paths is 3 × 3 × 3 × 3 × 3, which is 35 = 243.

That is the whole meaning of the number. A 243-ways game is equivalent to a payline game with every possible line switched on, each line running left to right with one cell per reel. The same rule gives the other figures you see on ways slots: four rows over five reels is 45 = 1,024 ways, and five rows over five reels is 55 = 3,125.

Line games cover only a slice of those routes. On the same five-by-three grid:

Every cell is equally involved, too. Fix any one cell, on any reel, and the other four reels still offer 34 = 81 paths through it. On a line game the middle row usually carries more lines than the corners; on a ways game no position is better placed than another.

How a win is counted

The count comes from a multiplication, not from checking 243 paths one by one. For a given symbol, note how many times it shows on reel 1, on reel 2, on reel 3, and keep going until you reach a reel where it does not appear. Multiply those counts together. The result is the number of ways that symbol has paid, and the length of the run, three, four or five reels, decides which row of the pay table applies.

The run reaches reel 4 and stops at reel 5, so it is a four-of-a-kind. The number of ways is 1 × 2 × 1 × 2 = 4: four different paths through the grid each carry four fish. The game pays the four-fish amount four times.

Three details follow from that rule, and they explain most of the surprises people meet on ways slots.

  1. Reel 1 is the gate. If a symbol is missing from the first reel, its count is zero and the product is zero, however many copies fill reels 2 to 5.
  2. A gap ends the run. Fish on reels 1, 2, 4 and 5 but not 3 is a two-reel run, not a four. Reels 4 and 5 are never reached. For most symbols a two-reel run pays nothing.
  3. Each way is paid once, for its longest run. The four ways above are paid as four-of-a-kind. They are not also paid again as three-of-a-kind for reels 1 to 3.

Wilds slot into the same arithmetic. In most ways games a wild counts as a copy of whichever symbol it helps, so a wild on reel 3 of the toy screen would raise its count there from 1 to 2, and the total from 4 ways to 1 × 2 × 2 × 2 = 8. A single wild on a middle reel doubles or triples every win passing through that reel, which is why a well-placed wild can move a result so much more on a ways game than on a line game.

The ceiling is a screen where one symbol, or that symbol plus wilds, fills all fifteen cells. Then every reel counts 3, and the product is 35 = 243. Every possible path pays at once.

The short version: count the symbol on each reel from the left, stop at the first reel without it, and multiply. The product is the number of ways; the number of reels reached picks the pay.

What changes compared with paylines

The obvious change is that wins come more often. A cat on the top row of reel 1, the bottom row of reel 2 and the middle of reel 3 pays on a ways game. On a 20-line game it pays only if one of those twenty lines happens to follow that exact shape.

What does not change is the overall balance. A ways game checks more routes, so the individual pay amounts are set lower to match. Counting 243 paths instead of 20 says how many places a win can be found, not how generous the game is. The return is fixed by the pay table and the reel strips together, and the number of ways is only one input to that sum.

The betting also works differently. On a line game the bet is usually a line bet multiplied by the number of active lines, and some games let you switch lines off; a match on a line you have turned off pays nothing. On a 243-ways game all paths are always live, so there is a single total bet per spin and no way to leave a route uncovered.
