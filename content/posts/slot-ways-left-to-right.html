Count the fish on a ways-to-win screen and you will often find a dozen of them and no win. The symbols are there, but the game is not counting symbols. It is counting runs: chains of the same symbol on neighbouring reels, starting at the left-hand edge. The multiplication is covered in what 243 ways to win means; this post is about where a run may start and where it has to stop.

The rule in three parts

On a five-reel, three-row grid there are 15 cells, and 3 × 3 × 3 × 3 × 3 = 243 left-to-right paths through them. The usual rule for a ways game has three parts.

  1. Start on reel 1. A symbol must appear at least once on the first reel. Otherwise it has no ways at all.
  2. Stay adjacent. Each following reel, 2, 3, 4 and so on, must also show the symbol. The run ends at the first reel that does not.
  3. Count by multiplying. The ways are the number of matching cells on each reel in the run, multiplied together.

Where the symbol sits within a reel does not matter. Top, middle or bottom, a cell is a cell. Position only matters across reels: a run has to be unbroken, and it has to begin on the left.

Worked counts

Write a screen as five numbers: how many cells show the symbol on each reel, from reel 1 to reel 5. These are all arithmetic you can check on paper.

  • 1, 3, 3, 3, 3. One cell on reel 1 and every cell on the other four. That is 13 matching cells, and the run reaches reel 5, so the ways are 1 × 3 × 3 × 3 × 3 = 81.
  • 0, 3, 3, 3, 3. Take away the single cell on reel 1. That leaves 12 matching cells, and the ways are 0 × 3 × 3 × 3 × 3 = 0. Twelve symbols, no win.
  • 3, 3, 3, 3, 0. Now keep reel 1 and lose reel 5. The run stops after four reels with 3 × 3 × 3 × 3 = 81 ways, each of them a four-reel run.
  • 3, 3, 3, 0, 0. The run stops after three reels with 3 × 3 × 3 = 27 ways.
  • 3, 3, 0, 3, 3. A gap on reel 3 ends the run at two reels with 3 × 3 = 9 ways. The cells on reels 4 and 5 are never reached.

Compare the first two. The same twelve cells on reels 2 to 5 are worth 81 ways with one cell on reel 1 and nothing without it. Reel 1 is a gate, not just one reel of five.

Of the 243 paths, 81 pass through any given cell on reel 1 (3 × 3 × 3 × 3 = 81). Every path starts on reel 1, so a symbol that misses it can reach none of them.

The count is a product, so cells spread evenly across the early reels beat cells piled on one. And the worst screen is the best one shifted a single reel to the right: 16 ways become 0.

The 2·2·0·2·2 screen needs one caution. Its four ways are real, but they are a two-reel run, and the pay table decides what a run of that length pays. Many ways games start paying at three reels, so a two-reel run would pay nothing. The rule for the minimum run belongs to each game's own pay table, so check it before assuming.

Ways come from unbroken runs that start on reel 1. Count the symbol on each reel from the left, stop at the first reel without it, and multiply. A symbol missing from reel 1 has zero ways, whatever lands on the other four.

Wilds and the left edge

A wild is the exception that helps. In most ways games a wild stands in for the symbol being counted, so it raises the count on its reel. That includes reel 1: a wild there can open a run for a symbol that would otherwise have been shut out. If the 0·3·3·3·3 screen above had a wild on reel 1, it would count as one cell for the symbol, and the screen becomes 1·3·3·3·3, which is 81 ways. Reading a screen

Look at reel 1 first. If the symbol is not there, stop. If it is, move right one reel at a time, noting the count, until you reach a reel without it. Then multiply.

Some games do pay in both directions, with runs from the right-hand edge as well. That is a separate feature, so a game that offers it will say so. Without it, symbols that only appear on the right side of the grid are just decoration.
