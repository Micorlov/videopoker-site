React Three Fiber is a React renderer for Three.js, the popular 3D library for the web. It is made by the Poimandres (pmndrs) open-source collective.

It is not an agent skill but a code library. You describe the 3D scene you want, and your AI agent writes the components.

It is free under the MIT license. On 28 October 2026 the repository had about 33,000 stars on GitHub.

What it does

  • Every Three.js object becomes a JSX element: a mesh, a light or a camera is written like any other component.
  • Objects can react to state, clicks and hover, and each one can run its own animation on every frame.
  • The README says everything that works in Three.js works here, with no overhead, because the scene renders outside React.
  • It also works in React Native.

What you can add with it

A product model the visitor can rotate, a 3D hero section, or a small animated object behind a headline. Around it there is a large ecosystem: Drei adds ready-made helpers, and other packages add post-processing effects, physics and VR or AR.

What to know first

The version must match your React version: version 8 works with React 18, and version 9 works with React 19. The README also says you should know both React and Three.js before you start. If an agent writes the code for you, it still helps to understand what it builds. A 3D scene also adds weight to the page, so check how it loads on phones.

How to install it

npm install three @types/three @react-three/fiber

Then ask your agent for the scene you want, for example a model of your product that turns when you drag it.
