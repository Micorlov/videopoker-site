instagram-agent-skill is a set of thirteen skills for Claude that do the writing work of an Instagram account. You give it an idea, and it writes the Reel script, the caption, the carousel slides or the replies. Then it checks the text before you see it.

It is free and uses the MIT license. It needs no account, no API key and no connection to Instagram. On 20 October 2026 the repository had 2,031 stars on GitHub.

The thirteen skills

Each skill is a command you type in Claude Code:

  • /ig-reel turns one idea into a Reel: three hooks from 26 hook formulas, each with a score, then the script, the text on screen and a timed plan.
  • /ig-viral looks at Reels in your niche and ranks them by how far each one beat its own account’s usual views.
  • /ig-caption writes the caption and shows the first 125 characters, which is what the feed shows before “more”.
  • /ig-carousel writes swipe posts: the cover, the text for each slide, and 1080×1350 images.
  • /ig-story plans the daily stories and which sticker to use for each one.
  • /ig-profile scores your profile out of 100 and rewrites the parts that lost points.
  • /ig-plan plans the week: what to post, in which format and when.
  • /ig-human cleans text so it sounds less like AI. More on this one below.
  • /ig-comment writes comments for other people’s posts.
  • /ig-reply sorts the comments under your own post and writes the replies.
  • /ig-dm writes direct messages: the first message, a collaboration pitch and two follow-ups.
  • /ig-repurpose turns one video, podcast or newsletter into a week of Reels and carousels.
  • /ig-audit looks back at what you already posted and ranks it.

The humanizer

/ig-human runs two small Python scripts on your computer. The first one removes invisible characters that often come with AI text, such as zero-width spaces and soft hyphens. It changes long dashes and curly quotes to plain ones, and it swaps 154 stock phrases, such as “stop scrolling” or “follow for more”, for plain words or deletes them.

The second script gives the text a score out of 100 from five checks: how much the sentence length varies, how many concrete details there are, how many stock phrases are left, typing marks like long dashes, and sentence patterns that sound written by a machine. In the repository’s own example, a bad caption scores 32.5 and is flagged. After cleaning it scores 79.7 and passes.

These checks are simple rules that run on your computer. They are not an AI detector service, and the repository says clearly that nothing can promise text will never be flagged.

What it does not do

It does not post to Instagram, and it does not log in as you. Every skill ends with text you can copy, and you post it yourself. The repository explains why: tools that post, comment or send messages automatically break Instagram’s terms and can get an account blocked.

The README is also honest about the hook score. In its own test it was good at catching weak hooks, but it could not tell which of two good hooks would do better.

How to install it

The simplest way is to paste the repository link into Claude Code and ask it to install the skill:

https://github.com/Jakeschincariol/instagram-agent-skill

Install this skill, then confirm /ig-reel works.

Or do it yourself in the terminal:

git clone https://github.com/Jakeschincariol/instagram-agent-skill.git
cp -r instagram-agent-skill/skills/ig-* ~/.claude/skills/

Or install it as a Claude Code plugin:

/plugin marketplace add Jakeschincariol/instagram-agent-skill
/plugin install instagram-agent

Every skill reads one file that describes how you talk. Before you start, fill in templates/voice.md and save it as ~/.claude/instagram/voice.md.
