Stop Slop is a skill for removing AI tells from prose, written by Hardik Pandya. It works with Claude and, as the README says, with any language model: you can load it as a skill, add it to a project or paste its rules into a system prompt.

It is free under the MIT license. On 26 October 2026 the repository had about 18,000 stars on GitHub.

What it catches

  • Filler phrases: throat-clearing openers, emphasis crutches, business jargon, vague statements and all adverbs.
  • Stock structures: contrasts like “not X, it’s Y”, dramatic fragments, rhetorical setups and a narrator who watches from a distance.
  • Sentence habits: em dashes, sentences that start with a question word, passive voice and lazy extremes like “always” and “never”.

The rules it follows

The core of the skill is eight rules. Among them: use active voice with a real person doing something, name the specific thing instead of making a vague claim, vary the length of sentences, and trust the reader instead of explaining everything twice. It also rewrites any line that sounds like a ready-made quote.

How it checks the result

After writing, the model rates the text from 1 to 10 on five points: directness, rhythm, trust in the reader, authenticity and density. If the total is below 35 out of 50, it revises the text.

The repository also has reference files with the phrases and structures to avoid, plus before-and-after examples. They load only when they are needed.

What to know first

It is a writing skill, not a coding tool, and it is small: one instruction file and three reference files. Its rules are strict on purpose, with no adverbs and no em dashes at all. The files are plain text, so you can edit any rule that does not fit your own style.

How to install it

In Claude Code, add the folder as a skill, for example by cloning it into your skills folder:

git clone https://github.com/hardikpandya/stop-slop.git ~/.claude/skills/stop-slop

In Claude Projects, upload the instruction file and the reference files to the project knowledge. With other models, put the instruction file in the system prompt.
