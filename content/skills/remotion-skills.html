Remotion is a framework for making videos with React. Remotion Agent Skills is the official set of skills with the best practices for working in Remotion projects. The team says they are useful for agents like Claude Code, Codex, Kimi Code and Cursor.

On 26 October 2026 the skills repository had about 5,700 stars on GitHub, and the main Remotion repository had about 67,000.

What the skills do

  • remotion-create starts a new project or composition, for example “Make a promo video for a record store”.
  • remotion-markup holds the rules for compositions, animation, layout, type, media, effects, audio and timing.
  • remotion-studio opens the Studio to preview the video, and remotion-render renders it to a video file or a still image.
  • remotion-captions helps with captions and subtitles, and remotion-maps with map animations and routes.
  • remotion-docs searches the Remotion documentation, and remotion-upgrade updates Remotion and the installed skills.
  • remotion-best-practices covers all of the others, for when you are not sure which one to use.

How it works

You describe the video. The agent writes it as React components, lets you check it in the Studio and renders the file. Because the video is code, you can change one line and render it again.

What to know first

The skills repository does not list a license of its own, and Remotion itself has a special license. It is free for individuals, for companies with up to 3 employees and for non-profits, even for commercial videos. Larger for-profit companies need a company license.

How to install it

Run this in your project:

npx skills add remotion-dev/skills

You can also add the skills when you create a new Remotion project:

bun create video

Then ask the agent, for example: “Create an animated title card using Inter.”
