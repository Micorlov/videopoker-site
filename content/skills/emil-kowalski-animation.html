A skill is a pack of instructions you add to a coding tool.

Emil Kowalski's project is a set of skills for people who design and build. They come from his years at Vercel and Linear.

The README is specific. The tools pick the wrong pieces.

When something appears, they start slow and then speed up. They should do the opposite. Start fast, then settle.

A button gets a hard border when a soft shadow was the right mark. Small choices like that add up.

The README calls the set a short path to a page that stands apart from that generic work.

What changes

Two skills cover the motion.

emil-design-eng is mostly about how things move, plus a little design advice.

animate builds a motion from scratch. It chooses the curve, the time, and what moves.

The same project has more skills. They help you check motion, speed, and React Native apps.

The README points to aiforui.dev for news.

  • Usual result. Something appears and starts slow, and a hard border sits where a shadow belongs.
  • Emil Kowalski. The curve, the time, and what moves, chosen on purpose.
