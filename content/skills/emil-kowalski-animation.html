Emil Kowalski's skills on GitHub

Emil Kowalski's repository is a set of skills for designers and engineers, drawn from his years at Vercel and Linear. The README's complaint is specific: agents do not pick the right ingredients. An enter animation gets ease-in when it should be ease-out. A control gets a solid border when a soft shadow was the right mark. Small choices like that add up. The README calls the set a shortcut to an interface that stands out from that generic work.

What changes

The two skills that cover the motion are emil-design-eng and animate. emil-design-eng is mostly animation, plus some design advice. animate builds an animation from scratch and chooses the curve, the duration and the properties. The same repository has further skills for reviewing motion, performance and React Native. The README points to aiforui.dev for updates.

  • Default. An enter animation that eases in, and a hard border where a shadow belongs.
  • Emil Kowalski. The curve, the duration and the properties, chosen on purpose.

How to install

npx skills@latest add emilkowalski/skills
