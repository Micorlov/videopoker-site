Agent Skills for Context Engineering is an open collection of skills by Muratcan Koylan. It is meant for people who build AI agents, and the skills work with Claude Code, Cursor, Codex and other platforms that support skills.

It is free under the MIT license. On 26 October 2026 the repository had 18 skills and about 18,000 stars on GitHub, and it is cited in academic papers, including a survey on agent harness engineering by researchers from CMU, Yale, other universities and Amazon.

What context engineering means

Prompt engineering is about writing good instructions. Context engineering covers everything the model reads: the system prompt, tool definitions, documents it looks up, the message history and tool output. As that grows, models get worse in predictable ways, for example they lose track of what sits in the middle. The goal is the smallest set of useful tokens that gets the job done.

What the skills cover

  • Basics: what context is, how it fails and how to compress long sessions.
  • Architecture: multi-agent patterns, memory systems, tool design and files as extra memory.
  • Operations: compaction, masking and caching, plus evaluation and LLM-as-a-judge methods.
  • Long-running agents: task briefs for agents that work alone for a long time, harness design and self-improvement loops.
  • Project development: whether a language model fits the task at all, and how to plan pipelines and costs.

The skills load in stages. At first the agent sees only their names and short descriptions, and the full text loads only when a task needs it.

What to know first

This is knowledge for building agents, not a switch that makes Claude use fewer tokens in your own chats. Its optimization skills are about token efficiency in the agent systems you design. Many of its scripts are Python pseudocode, written to explain ideas rather than to run as a finished product.

How to install it

In Claude Code:

/plugin marketplace add muratcankoylan/Agent-Skills-for-Context-Engineering
/plugin install context-engineering@context-engineering-marketplace

In Cursor, Codex and other tools, copy the skill folders you want into that tool’s skills folder, for example .cursor/skills. Keep each skill as a folder, not a single file.
