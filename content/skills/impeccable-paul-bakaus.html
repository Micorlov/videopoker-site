A skill is a pack of instructions you add to a coding tool.

Impeccable is Paul Bakaus's design skill. The project page calls it one skill, 24 commands, a way to try changes in the browser, and 59 checks for design made by a coding tool. The docs are at impeccable.style.

What the usual result gets wrong

The README says tools trained on the same templates repeat the same signs.

The Inter font. A fade from purple to blue. Cards inside cards. Gray text on a colored background. A round icon tile above every heading.

  • Usual result. The same font, a purple fade, and cards inside cards.
  • Impeccable. 24 shared commands, and 59 checks that flag those signs.

What you can ask

The commands are the shared words.

You start with /impeccable init. It writes who the product is for, in a file called PRODUCT.md, before the later commands run.

You use /impeccable layout to fix spacing and rhythm on a page that already exists.

You use /impeccable polish, /impeccable typeset, and /impeccable audit as other passes once the page is up.

You use /impeccable document to write a DESIGN.md file from the code you already have.

How to install

In the project you want, run the installer. Then run /impeccable init inside the coding tool.

Add --providers, and --scope=project or --scope=global, if you want to skip the questions.

npx impeccable install
