The Impeccable repository on GitHub

Impeccable is Paul Bakaus's design skill for coding agents. The repository describes it as one skill, 24 commands, live browser iteration, and 59 detector rules for AI-generated frontend design. The documentation is at impeccable.style.

What the default gets wrong

The README's point is that models trained on the same templates repeat the same tells: the Inter font, a purple-to-blue gradient, cards nested in cards, gray text on a colored background, and a rounded icon tile above every heading.

  • Default. The same font, a purple gradient, and cards inside cards.
  • Impeccable. Twenty-four shared commands, and 59 checks that flag those tells.

What you can ask it

The commands are the vocabulary. /impeccable init records who the product is for, in PRODUCT.md, before later commands run. /impeccable layout repairs spacing and rhythm on a page that already exists. /impeccable polish, /impeccable typeset and /impeccable audit are the other passes for a page that is already up. /impeccable document writes DESIGN.md from the code you have.

How to install

From the project you want it in, run the installer, then /impeccable init inside the coding tool. Pass --providers and --scope=project or --scope=global to skip the questions.

npx impeccable install
