The gstack repository on GitHub

gstack is a free, open-source repository by Garry Tan, President and CEO of Y Combinator. The repository description calls it his Claude Code setup: 23 opinionated tools that serve as CEO, Designer, Eng Manager, Release Manager, Doc Engineer, and QA. On 16 October 2026 it had 136,673 stars and 20,279 forks. It is MIT licensed, written in TypeScript, and the last push was that same day.

The six roles

The GitHub description names six roles. The README's sprint table is longer than the "23 tools" line, so these cards are the roles, not every command.

  • CEO. Rethink the product before the code starts.
  • Designer. Score the design, then fix what the score finds.
  • Eng Manager. Lock the architecture, the edge cases and the tests.
  • Release Manager. Run the checks, push, and open the pull request.
  • Doc Engineer. Compare the change with the documentation.
  • QA. Try the real behavior and keep a failing test.

The sprint

The README says the skills run in sprint order, and each one reads what the step before it wrote. /office-hours writes a design note that the planning step reads. /plan-eng-review writes a test plan that /qa picks up.

Useful commands inside that order are /office-hours, /plan-ceo-review, /plan-eng-review, /plan-design-review, /autoplan, /review, /cso, /design-review, /qa, /qa-only, /ship, /land-and-deploy, /document-release, /retro and /learn. Separate power tools cover a second opinion (/codex), safety (/careful, /freeze, /guard) and upgrading (/gstack-upgrade). Uninstall is ~/.claude/skills/gstack/bin/gstack-uninstall.

Who it is for

The README names three readers: founders and CEOs who still ship, people new to Claude Code who want roles instead of a blank prompt, and tech leads who want review, testing and a release check on every pull request.

How to install

The README requires Claude Code, Git, and Bun 1.4.2 or newer. Setup refuses Bun older than 1.3.3. Node.js is required on Windows only. The default install is Claude Code. ./setup --host auto installs for the other agents the README lists.

git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup

The README's suggested first commands are /office-hours, then /plan-ceo-review, /review and /qa.

Team mode is optional. From the gstack folder the command is ./setup --team, then gstack-team-init required, then a commit of .claude/ and CLAUDE.md. Use optional instead of required when teammates should not be blocked.
