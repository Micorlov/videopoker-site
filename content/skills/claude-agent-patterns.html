A reel by Evgenii Arsentev lists seven new Claude agents and says they can replace a whole company. The patterns are real. Calling them new is the sales line.

The seven names

The reel uses everyday names. Here is each one, next to the page that already described that kind of work.

  1. Tool agent. The reel says Claude uses Gmail, Notion, and other apps through MCP. Anthropic opened MCP on 25 November 2024. It is a shared way to connect an assistant to tools and files. The first example servers include Google Drive, Slack, and GitHub. The December article calls the basic piece an augmented model: a model plus tools.
  2. Skills agent. The reel says you write the instructions once, in a file called SKILL.md, inside .claude/skills/. Anthropic published Agent Skills on 16 October 2025, later than the article. A skill is a folder with a SKILL.md file. Claude reads it when the task fits. Claude Code’s docs put a project skill at .claude/skills/.
  3. Sequential agents. The reel says the tasks run in a chain. The article calls this prompt chaining. Each step reads what the step before it wrote.
  4. Parallel agents. The reel says the agents work side by side. The article calls this parallelization. Split the job, run the pieces at the same time, then join the answers.
  5. Router. The reel says a router sends each request to the right agent. The article calls this routing. Sort the request, then send it down the matching path.
  6. Human in the loop. The reel says the agent does the work, then asks you to confirm before an important action, such as sending an email. The article does not give this its own name in the pattern list. It does say an agent can stop and ask a person at a checkpoint, or when it is stuck.
  7. Orchestrator. The reel says one lead agent manages a team. The article calls this orchestrator-workers. One model splits the job, hands the pieces to worker models, and combines what they return.

What the article also has

The article describes one more pattern the reel skips. One model writes. Another model checks. They loop until the check is good enough. The article calls this evaluator-optimizer.

What came when

Put the dates in order. MCP launched on 25 November 2024. The article, “Building effective agents”, came on 19 December 2024. It already has prompt chaining, routing, parallelization, orchestrator-workers, and evaluator-optimizer. Agent Skills came later, on 16 October 2025.

  • The reel. Seven new agents, ready to replace a company.
  • The pages. Real patterns. Most of them were already written down in December 2024.
