The Taste Skill repository on GitHub

Taste Skill, by Leonxlnx, is a set of agent skills that make a coding agent design a website instead of assembling the average landing page. The default skill, install name design-taste-frontend, is art direction for landing pages, marketing sites, portfolios and product pages.

Past the average page

The default skill is built from that study of 247 curated sites. A build reads the brief, a script deals three of 20 researched directions, and the agent picks one. It then finds real pictures, checks the page in a browser at three widths, and fails the page on slop. After that it looks at its own screenshots and fixes the top three problems, up to three rounds.

  • Default. An average landing page assembled from the usual parts.
  • Taste Skill. One direction from the study, then a check in a real browser.

How to install

The README says the default skill runs on Node 22 or newer and needs Chrome, Edge or Chromium. It does not install a browser and it does not need an API key. Install every skill in the repo with the first command, or only the default skill with the second.

npx skills add https://github.com/Leonxlnx/taste-skill
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
