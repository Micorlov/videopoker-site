A skill is a pack of instructions you add to a coding tool.

Taste Skill, by Leonxlnx, is a set of these packs. They push a coding tool to design a site, instead of building the usual landing page.

The main one is named design-taste-frontend. It is for landing pages, marketing sites, portfolios, and product pages.

Past the usual page

The main skill comes from that study of 247 chosen sites.

A build starts by reading what you want. A script then offers three directions out of 20 it has studied. The tool picks one.

It finds real pictures. It checks the page in a browser at three widths. It fails the page if the page looks generic.

Then it looks at its own screenshots and fixes the top three problems. It can do that up to three times.

  • Usual result. A landing page made from the usual parts.
  • Taste Skill. One direction from the study, then a check in a real browser.

How to install

The README says the main skill needs Node 22 or newer. It also needs Chrome, Edge, or Chromium.

It does not install a browser. It does not need an API key.

The first command installs every skill in the project. The second installs only the main one.

npx skills add https://github.com/Leonxlnx/taste-skill
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
