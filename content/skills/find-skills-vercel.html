find-skills is a skill for coding agents that finds other skills for you. You say what you want to do, and it looks for skills that fit the task, checks them, and offers to install the best one.

The skill lives in the vercel-labs/skills repository on GitHub. On 19 October 2026 skills.sh showed 3.9 million installs for it, the most of any skill on the site.

What find-skills is

find-skills is a single SKILL.md file with instructions for the agent. It has no catalogue of its own. It tells the agent to use the Skills CLI, an open tool for installing skills, which searches the skills.sh directory. On 19 October 2026 that directory listed about 1.4 million skills. It works in Claude Code, Cursor, GitHub Copilot and many other coding agents.

What it tells the agent to do

  1. Work out what you need: the area, such as testing or design, and the exact task.
  2. Check the skills.sh leaderboard first, because popular skills for common tasks are often already there.
  3. If the leaderboard does not cover it, search with a short query, for example “npx skills find react performance”.
  4. Check every result before suggesting it. Prefer more than 1,000 installs, known sources such as Vercel, Anthropic or Microsoft, and repositories with at least 100 stars on GitHub.
  5. Show you the options: what each skill does, its install count, its source, and the command to install it.
  6. Offer to install the one you choose.

What it does not do

The skill does not keep a database of skills. It searches skills.sh each time. It also does not install skills on its own: it shows you a list and asks first.

One warning

Anyone can publish a skill, and a skill is instructions that your agent will follow. That is why find-skills tells the agent to check installs, source and stars before it suggests anything. Read a skill's SKILL.md yourself before you install it, especially if it comes from an unknown author.

How to use it

You need Node.js 18 or newer. Run this command in your terminal:

npx skills add vercel-labs/skills --skill find-skills

Then ask your agent in plain words, for example “find a skill for writing changelogs”. You can also search yourself with “npx skills find” and a few words about the task.
