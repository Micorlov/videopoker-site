REA stands for Reverse Engineer Anything. It is an MCP server, a set of tools your AI coding agent can call. With it the agent can inspect an app that is installed on your computer, even when you do not have its source code. It finds the part of the app behind a feature, explains how that feature works, and shows the evidence for each conclusion.

It is open source under the MIT license and runs on Node.js. It works with Claude Code, Codex, Cursor, Gemini CLI, Grok Build and other agents that support local MCP servers. On 22 October 2026 the repository had about 359,000 stars on GitHub, and the latest version on npm was 6.7.0 from 18 October 2026.

What it can look at

REA connects your agent to tools for many kinds of targets. The main ones are:

  • JavaScript and Electron apps, such as many desktop chat and note apps. REA finds the modules, the imports and how the parts of the app talk to each other.
  • Websites, through a Chrome-family browser. REA reports the page structure, the scripts and the network requests.
  • Native programs. With Hopper, Ghidra or IDA installed, REA returns pseudocode, assembly, strings and the calls between functions.
  • Android APKs, .NET programs, Unity and Godot game files, and saved network captures.

Static JavaScript and .NET inspection only read the files and do not run the app. Native analysis needs one of the three engines above.

How the agent uses it

After setup you ask your agent in plain words, for example:

Understand how search works in the Notes app,
show me the evidence, and build a similar
feature for my project.

The agent calls REA to inspect the app and trace the code behind the feature. REA answers with what it found, where it found it, and what it could not confirm. The agent then explains the feature, or writes and tests your own version of it.

The project shows real examples on its website: following a clipboard feature through the Notion desktop app, and rebuilding a sound calculation from the 1990s game DX-Ball so that it matches the original byte for byte.

What stays on your computer

REA analyzes the app on your own computer and does not upload it. Your agent does see the results, and the AI model behind your agent follows its own provider’s data rules.

REA only sees what is on your computer. Logic that runs on a company’s servers, such as billing or accounts, is not in the app, so REA cannot read it.

What it is not for

Videos about REA often say it can clone any app. That is not what the project says. Its goal is to understand how a feature works and then build your own version. Its rules say not to use it to copy someone else’s protected code or assets, break DRM or license checks, or make game cheats. Use it on software you own or are allowed to examine.

How to install it

You need Node.js 22.19 or newer and npm. Run this and choose your agents:

npx rea-agents setup

Setup adds REA to your agent, adds matching instructions, and backs up your old settings first. Restart your agent afterward. To use REA from the terminal as well:

npm install --global rea-agents
rea --help

The official sources are the morluto/rea repository, rea.tools and the rea-agents package on npm. A repository with a similar name is not from this project.
