A reel by @ii.systema says a developer burned 60 billion tokens, then published the rules file he uses for AI coding. The reel says the file makes the model look for simple solutions, read the documentation, and save your usage limits.

The developer is Marcos Hernanz. He worked on Next.js at Vercel. On 2 August 2026 he posted on X: “After doing ~60B tokens, this is my full AGENTS.md”. The post showed seven rules. A few hours later he replied with an eighth one, under the words “Almost forgot”.

What an AGENTS.md is

AGENTS.md is a plain text file in the main folder of a project. Coding agents read it before they start work, so you write your rules once instead of in every chat. Claude Code reads it when the project has no CLAUDE.md file.

The eight rules, in plain words

  1. Do not keep old code alive. When something is replaced, delete the old path. Do not add fallbacks or layers to keep it working.
  2. Pick the simplest solution that fully does the job today. Do not add settings or layers “just in case”.
  3. Grow in small steps. First build the smallest version that works from start to finish. Then add one feature at a time on top of something that already works.
  4. Keep parts separate. Each part does one job.
  5. Use a good, well-known library when it makes things simpler or more reliable. Do not rewrite common features without a reason.
  6. Check what the project already has before you add a package or write your own code. Read the library's documentation and types before you decide it cannot do something.
  7. Decide for the long term. No quick fix that is meant to be thrown away later.
  8. Before you design something, look at how good, established products solve the same problem. Copy their proven patterns instead of inventing your own.

Why it can save tokens

Most of these rules tell the agent to write less: no extra layers, no copies of libraries, no code kept only for old versions. Less code means less to read, fix, and explain on the next turn. Rule six is the one the reel calls “read the documentation”. Marcos does not give a number for how many tokens the file saves.

One warning from the author

Marcos added a note under his post: he only uses this file for side projects, and you should not use it in production if you do not want to destroy your codebase. The first rule is the risky one. In a real product, deleting old paths can break users who still need them.

How to use it

Create a file called AGENTS.md in the main folder of your project. Copy the eight rules from his two posts, and change any rule that does not fit your project. If you use Claude Code and already have a CLAUDE.md, add one line to it so Claude reads both:

@AGENTS.md
